# Methods

The engine, with no <Fw react="component" flutter="widget" /> anywhere in it. Two documents in and what changed out, two pictures in and what changed out, a patch read or written.

| Page | What it does |
| --- | --- |
| [`diffText`](./diff-text) | Compares two documents by line, then inside each changed line. |
| [`diffWords`](./diff-words) | Compares two lines a word at a time. |
| [`diffCharacters`](./diff-characters) | The same comparison, a character at a time. |
| [`diffSequence`](./diff-sequence) | Compares two sequences of tokens, whatever the tokens are. |
| [`formatPatch`](./format-patch) | Writes a comparison out as a unified diff. |
| [`parsePatch`](./parse-patch) | Reads a unified diff back into comparisons. |
| [`diffImage`](./diff-image) | Compares two pictures pixel by pixel. |
| [`diffImages`](./diff-images) | Compares several pictures at once against a baseline. |
| [`imageSimilarity`](./image-similarity) | Says how alike two pictures are, as one number. |
| [`imagesSimilarity`](./images-similarity) | Says how alike several are, and which is the odd one out. |
| [`paintDiffImage`](./paint-diff-image) | Turns the mask of a comparison into a picture. |
| [`paintDiffImages`](./paint-diff-images) | The same, for a comparison of several. |
