# Types

What the functions return and what the <Fw react="components" flutter="widgets" /> take. Nothing here is something to call; these are the shapes the rest of the reference names.

| Page | What it is |
| --- | --- |
| [`DiffOptions`](./diff-options) | How two documents are compared. |
| [`DiffResult`](./diff-result) | What `diffText` returns. |
| [`DiffRow`](./diff-row) | One row of a comparison, and the lines inside it. |
| [`DiffChange`](./diff-change) | One run of changed lines. |
| [`DiffStats`](./diff-stats) | How many lines ended up where. |
| [`DiffPixels`](./diff-pixels) | A picture as bytes. |
| [`DiffImageOptions`](./diff-image-options) | How two pictures are compared. |
| [`DiffImageResult`](./diff-image-result) | What `diffImage` returns. |
| [`DiffImageRegion`](./diff-image-region) | One rectangle of changed pixels. |
| [`DiffImageStats`](./diff-image-stats) | How much of the frame ended up where. |
| [`DiffImagesOptions`](./diff-images-options) | How several pictures are compared. |
| [`DiffImagesResult`](./diff-images-result) | What a comparison of several pictures returns. |
| [`DiffineStrings`](./diffine-strings) | Every word the views put on the screen. |
| [`DiffineFont`](./diffine-font) | The typeface the documents are drawn in. |
| [The list of languages](./diffine-languages) | Every language the syntax highlighting accepts. |
| [`DiffineRender`](./diffine-render) | Something of the application's own, beside or under a line. |
| [`DiffineHighlight`](./diffine-highlight) | An application's own highlighter, in place of a language. |
