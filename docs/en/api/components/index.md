# Components

Two <Fw react="components" flutter="widgets" />, and each of them draws both halves of what it is for: a comparison somebody reads, and the fields somebody types into. Which of the two is `mode`.

| Page                        | What it draws                                       |
| --------------------------- | --------------------------------------------------- |
| [`TextDiff`](./text-diff)   | Two documents, side by side or in one column.       |
| [`ImageDiff`](./image-diff) | Two pictures, or a list of them against a baseline. |
