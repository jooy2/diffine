# 타입

함수가 돌려주는 값과 <Fw react="컴포넌트" flutter="위젯" />가 받는 값입니다. 여기에 부를 수 있는 것은 없고, 이 문서의 나머지가 이름으로 부르는 모양만 있습니다.

| 문서                                         | 무엇인가                                   |
| -------------------------------------------- | ------------------------------------------ |
| [`DiffOptions`](./diff-options)              | 두 문서를 어떻게 비교할지.                 |
| [`DiffResult`](./diff-result)                | `diffText`가 돌려주는 값.                  |
| [`DiffRow`](./diff-row)                      | 비교 결과의 행 하나와 그 안의 줄.          |
| [`DiffChange`](./diff-change)                | 이어진 변경 한 덩어리.                     |
| [`DiffStats`](./diff-stats)                  | 줄이 어디로 갔는지에 대한 집계.            |
| [`DiffPixels`](./diff-pixels)                | 바이트로 본 이미지.                        |
| [`DiffImageOptions`](./diff-image-options)   | 두 이미지를 어떻게 비교할지.               |
| [`DiffImageResult`](./diff-image-result)     | `diffImage`가 돌려주는 값.                 |
| [`DiffImageRegion`](./diff-image-region)     | 바뀐 픽셀이 모인 사각형 하나.              |
| [`DiffImageStats`](./diff-image-stats)       | 프레임이 어디로 갔는지에 대한 집계.        |
| [`DiffImagesOptions`](./diff-images-options) | 여러 이미지를 어떻게 비교할지.             |
| [`DiffImagesResult`](./diff-images-result)   | 여러 장을 한 번에 비교했을 때 돌아오는 값. |
| [`DiffineStrings`](./diffine-strings)        | 화면에 나오는 모든 낱말.                   |
| [`DiffineFont`](./diffine-font)              | 문서를 그리는 서체.                        |
| [언어 목록](./diffine-languages)             | 구문 강조가 받는 언어 전부.                |
| [`DiffineRender`](./diffine-render)          | 줄 옆이나 아래에 넣는 애플리케이션의 것.   |
| [`DiffineHighlight`](./diffine-highlight)    | 애플리케이션이 직접 만든 강조기.           |
